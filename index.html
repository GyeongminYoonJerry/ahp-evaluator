# AHP 평가 웹 버전 - 세팅 가이드 (9PSF / Sub-PSF 전용) > **이 버전의 특징:** > - 9개 PSF 그룹: Workload, Equipment/HSI, Procedure/Guideline, Experience/Training, > Communication, Environment, Work Process, Complexity, **Fitness for Duty** > - 각 PSF 그룹 **내부의 sub-PSF 간 비교만** 진행 (상위 PSF 간 비교 안 함) > - 가중치 산정: **정통 AHP 산술평균법** (Normalized Column Method) > - 원본 exe의 "행 합/전체 합" 방식과 다름 — 표준 교과서 방식으로 변경 > - 각 그룹 내 가중치 합 = 1.0 > - 총 9개 페이지, 약 207개 쌍대비교, 약 25~40분 소요 > - 시트 컬럼: 메타데이터 4개 + sub-PSF 60개 = **총 64개** > - 결과 컬럼명 형식: `Workload/근무시간`, `Equipment/HSI/장비 가용성(접근성)` 등 (그룹/Sub-PSF) 이 가이드를 그대로 따라하시면 됩니다. 약 **10분** 소요됩니다. --- ## 사전 준비 - Google 계정 (Gmail) - 이 폴더의 두 파일: - `index.html` (평가용 웹페이지) - `apps_script_code.gs` (서버 코드) --- ## STEP 1. Google Sheets 만들기 1. https://sheets.google.com 접속 2. 우상단 `+` 또는 "내용 없음" 시트 새로 만들기 3. 시트 이름을 **`AHP 평가 결과`** 등 알아보기 쉽게 변경 4. 이 시트의 탭에 `응답`이라는 이름이 자동 생성됩니다 (스크립트가 자동 처리) --- ## STEP 2. Apps Script 코드 붙여넣기 1. Sheets 메뉴에서 **확장 프로그램(Extensions) > Apps Script** 클릭 2. 새 창이 열리면 기본 `function myFunction() { }` 코드 **전체 삭제** 3. `apps_script_code.gs` 파일의 **모든 내용을 복사해서 붙여넣기** 4. 상단 입력란에서 프로젝트 이름을 **`AHP 결과 수신`** 등으로 변경 5. **`💾 저장` (Ctrl+S)** 클릭 ### 설정 확인 (가장 위 상수 3줄) ```javascript const RECIPIENT_EMAIL = "jerry@bees.pro"; // ← 결과 받을 메일 const DRIVE_FOLDER_NAME = "AHP_평가결과"; // ← Drive 폴더명 (자동 생성됨) const SHEET_NAME = "응답"; // ← 시트 탭 이름 ``` `RECIPIENT_EMAIL`이 본인이 받을 메일 주소가 맞는지 확인하세요. 다르면 수정 후 저장. --- ## STEP 3. 권한 승인 (한 번만) 1. 상단 함수 선택 메뉴에서 **`testRun`** 선택 2. **`▶ 실행`** 버튼 클릭 3. **"승인 필요" 팝업** 뜸 → "권한 검토" 클릭 4. 본인 Google 계정 선택 5. **"이 앱은 Google에서 확인하지 않았습니다"** 경고 뜸 → 좌하단 **"고급"** 클릭 → **"AHP 결과 수신(안전하지 않음)(으)로 이동"** 클릭 → 권한 목록(Drive, Gmail, Sheets) 확인 후 **"허용"** 6. 실행 완료 후, 다음을 확인: - 본인 Gmail에 **테스트 메일** 도착했는지 확인 - Google Drive에 **`AHP_평가결과`** 폴더가 생기고 안에 테스트 TXT 파일이 있는지 확인 - 현재 Sheets에 **`응답`** 탭이 생기고 한 행이 추가됐는지 확인 세 가지 모두 확인되면 서버 세팅 완료입니다. --- ## STEP 4. 웹앱으로 배포 1. Apps Script 우상단 **`배포(Deploy)` > `새 배포(New deployment)`** 클릭 2. 좌상단 톱니바퀴 아이콘 → **`웹 앱(Web app)`** 선택 3. 다음 설정 입력: - **설명**: `AHP Evaluator v1` (자유) - **다음 사용자로 실행(Execute as)**: **`본인 (your email)`** - **액세스 권한(Who has access)**: **`모든 사용자(Anyone)`** ← 매우 중요 4. **`배포(Deploy)`** 클릭 5. 권한 추가 승인 팝업이 뜨면 STEP 3과 동일하게 진행 6. 배포 완료 후 표시되는 **웹앱 URL**을 복사 - 형식: `https://script.google.com/macros/s/AKfycb..../exec` --- ## STEP 5. HTML 파일에 URL 입력 1. `index.html` 파일을 메모장 또는 VSCode로 열기 2. 다음 줄을 찾기 (29번째 줄 근처): ```javascript const APPS_SCRIPT_URL = "PASTE_YOUR_APPS_SCRIPT_WEBAPP_URL_HERE"; ``` 3. `PASTE_YOUR_APPS_SCRIPT_WEBAPP_URL_HERE` 부분을 STEP 4에서 복사한 URL로 교체: ```javascript const APPS_SCRIPT_URL = "https://script.google.com/macros/s/AKfycb..../exec"; ``` 4. 저장 (Ctrl+S) --- ## STEP 6. 호스팅 (핸드폰에서 접속 가능하게) 세 가지 방법 중 선택: ### 방법 A. GitHub Pages (무료, 권장) 1. https://github.com 가입/로그인 2. `New repository` → 이름 `ahp-evaluator` 등, **Public** 선택 3. `Add file > Upload files` → `index.html` 업로드 4. `Settings > Pages` → Source를 `main` 브랜치 / `/ (root)` 선택, Save 5. 1~2분 후 생성된 URL을 핸드폰에서 접속 - 형식: `https://본인아이디.github.io/ahp-evaluator/` ### 방법 B. Netlify Drop (무료, 가장 간단) 1. https://app.netlify.com/drop 접속 2. `index.html` 파일을 페이지로 **드래그 앤 드롭** 3. 즉시 URL 생성됨 (예: `https://random-name.netlify.app`) 4. 핸드폰에서 그 URL로 접속 ### 방법 C. 로컬에서만 테스트 본인 컴퓨터에서만 테스트하려면: ```bash # 명령 프롬프트(cmd)에서 cd "C:\Users\gkdls\Desktop\Gyeong\70_claude_rail\철도HRA 개발\AHP_evaluator_웹버전" python -m http.server 8000 ``` 브라우저에서 `http://localhost:8000` 접속. 핸드폰에서 접속하려면 같은 WiFi에서 `http://컴퓨터내부IP:8000` 입력. 다만 외부망에서는 안 됩니다. --- ## 사용 흐름 평가자가 핸드폰으로 URL 접속 → 이름·소속·직책 입력 → 9페이지의 sub-PSF 쌍대비교 (총 207개) → **제출** 버튼 누르면: 1. ✅ Google Sheets에 한 행 자동 추가 (sub-PSF 60개 컬럼) 2. ✅ jerry@bees.pro로 메일 자동 발송 (TXT 첨부, `[9PSF/SubPSF]` 머리표) 3. ✅ Google Drive `AHP_평가결과_9PSF` 폴더에 TXT 파일 저장 4. ✅ 평가자에게는 "완료" 메시지만 표시 (결과 내용 비공개) --- ## 문제 해결 ### "결과가 안 와요" - Apps Script 편집기에서 `testRun` 함수를 다시 실행 → 메일 도착하는지 확인 - 안 오면 권한이 잘못 부여된 것. STEP 4 배포를 새로 다시 진행 - 스팸함도 확인 ### "URL을 변경했어요" - HTML의 `APPS_SCRIPT_URL`도 새 URL로 업데이트 필요 - 호스팅된 파일도 다시 업로드 ### "코드 수정 후 변화가 없어요" - Apps Script는 수정 후 **`배포 관리(Manage deployments)` > 연필 아이콘 > Version: New version`** 으로 새 배포 필요 - 새 배포할 때마다 URL은 동일하게 유지됨 (같은 배포 슬롯 업데이트) ### "Environment 카테고리(14개)가 너무 길어요" - 원본 알고리즘 그대로라 91개 비교 필요. 줄이려면 인자 수를 줄여야 함 - `index.html` 내 `factors["Environment"]` 배열에서 항목을 삭제하면 그만큼 비교 횟수가 줄어듭니다 --- ## 직접 검증해야 할 부분 (사용 전) 1. **testRun 함수 실행**으로 메일·시트·Drive 3곳 모두 정상 작동 확인 2. **시트 컬럼 수가 64개**(메타 4 + sub-PSF 60) 인지 확인 3. **시트 첫 행 헤더**가 `Workload/근무시간`, `Equipment/HSI/장비 가용성(접근성)` 형태인지 확인 4. **각 그룹별 가중치 합이 1.0인지** 시트에서 SUM 함수로 확인 (예: E:J열 합 = 1) 5. **본인이 한 번 끝까지 응답**해보고, 받은 TXT의 sub-PSF 가중치가 시트와 일치하는지 확인 6. **이전에 만든 시트가 있다면** 헤더 구조가 다릅니다 — 기존 `응답` 탭을 삭제 후 `testRun` 재실행 권장 ## 주의: 가중치 계산 방식이 원본 exe와 다릅니다 - 원본 exe: `행 합 / 전체 합` (단순 방식) - 이 웹 버전: `정통 AHP 산술평균법` (정규화 열 평균) - 같은 응답이라도 두 방식의 가중치 값은 **소수점 단위로 다릅니다** (대소 순위는 보통 같음) - 과거 원본 exe 결과와 직접 수치 비교 시 차이가 발생함을 인지하세요 --- ## 파일 구조 ``` AHP_evaluator_웹버전/ ├── index.html ← 평가용 웹페이지 (호스팅) ├── apps_script_code.gs ← Apps Script 붙여넣기용 코드 └── 세팅가이드.md ← 이 파일 ```
